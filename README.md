## 📌 About This Repository

This repository contains my learning notes, technical explanations, security concepts, and practical observations from completing the **AI Security Path on TryHackMe**.

As AI systems and Large Language Models (LLMs) become increasingly integrated into real-world applications, understanding how they work and how they can be attacked is an important part of modern cybersecurity.

Through this learning path, I explored AI fundamentals, AI-specific vulnerabilities, LLM security, prompt injection, AI threat modelling, and techniques used to secure AI-powered applications.

The goal of this repository is to document my learning journey and build a strong foundation in **AI Security and AI Red Teaming**.

## 🎯 Learning Objectives

- Understand the fundamentals of Artificial Intelligence, Machine Learning, and Deep Learning.
- Explore how Large Language Models (LLMs) process instructions and generate responses.
- Understand common AI security threats and attack surfaces.
- Learn Prompt Engineering, Prompt Injection, and Jailbreaking concepts.
- Explore AI system architecture and security weaknesses.
- Understand AI threat modelling and attack methodologies.
- Study security risks in AI models, training data, and RAG systems.
- Learn how to identify and mitigate vulnerabilities in AI-powered applications.
- Understand AI forensics and the role of AI in cybersecurity investigations.
